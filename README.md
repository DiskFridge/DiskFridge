# 🧊 DiskFridge

**탈부착 자동화 콜드 스토리지 백업 장치**

---

### 0. 왜 만들었나?

   
대용량 데이터를 안정적으로 저장할 스토리지가 필요하여 다양한 매체를 검토했습니다.

USB와 SSD, DVD, 블루레이는 비용 대비 용량이 적고, 특히 광학 매체는 쓰기 횟수가 제한되어 제외했습니다.

LTO 테이프는 용량당 비용은 저렴하지만 전용 드라이브가 비싸고 구하기 어려우며, 특유의 소음과 느린 랜덤 읽기 속도 때문에 일상적인 용도로는 부적합했습니다. 

클라우드 스토리지는 신뢰성은 높으나 매달 고정 비용이 발생하고 보안 리스크가 존재했습니다. 

결국 소거법을 통해 가장 합리적인 대안인 하드디스크를 최종 저장매체로 선택하게 되었습니다.


데이터 무결성을 유지하기 위해서는 모든 저장 장치가 언젠가 반드시 고장 난다는 필연성을 전제하고 여러 디스크에 복제본을 다중 백업해야 합니다. 

이때 신품 하드디스크도 초기 불량이나 돌발 고장 가능성이 늘 존재하므로 가성비 좋은 중고 하드디스크를 사용하는 것도 훌륭한 대안이 됩니다.

특히 500GB 이하의 소용량 중고 하드디스크로 다중 백업을 구성하면 신품 대비 비용을 80% 이상 절감할 수 있어 비용 면에서 매우 유리합니다.

하지만 소용량 하드디스크 여러 개를 활용하는 방식은 곧 관리적·물리적인 한계에 부딪히게 됩니다.

디스크당 용량이 작아 동일한 수정 사항을 여러 디스크에 일일이 반복해서 반영해야 하는 번거로움이 생깁니다.

게다가 수십 개의 디스크를 PC 케이스 내부에 전부 장착하려 해도 메인보드의 SATA 포트 개수가 부족하며, 상시 구동에 따른 전력 소모 문제도 발생합니다.

더 큰 문제는 안정성입니다. 모든 디스크를 본체 내부에 상시 연결해 두면 낙뢰나 갑작스러운 전기적 이상이 발생했을 때 모든 하드디스크가 동시에 고장 날 위험이 있습니다.


이러한 한계를 극복하기 위해 디스크를 PC 내부에서 외부로 분리하고, 필요할 때마다 간편하게 탈착할 수 있는 핫스왑 베이 구조를 도입하게 되었습니다. 

모든 디스크가 상시 연결될 필요는 없으므로 LTO 라이브러리처럼 디스크를 필요할 때만 교체하여 사용하는 방식을 구상한 것입니다.

다만 하드디스크는 무게가 무거워 로봇 팔이나 캐리지로 직접 들어 옮기는 하드웨어 자동화에는 부적합했습니다. 

또한 일반적인 핫스왑 베이의 SATA 포트는 물리적인 탈부착 내구 수명이 그리 길지 않다는 문제가 있었습니다.

이에 따라 하드디스크 자체는 고정해 두고, 연결과 해제만을 캐리지가 자동으로 수행하는 구조로 방향을 잡았습니다.


연결 방식을 결정하는 과정에서 PC와 SATA 신호를 직접 연결하는 것은 까다로웠습니다.

SATA 케이블은 유연하지 못하고 딱딱하며 고정력도 부족하여, 반복적인 자동 탈부착 과정에서 신호선과 전원선의 접촉 불량 문제가 상시 발생할 수 있기 때문입니다.

규격 측면에서는 원래 외장용으로 설계되어 탈부착 횟수가 보장되는 USB 포트를 적용하는 것이 대안이 될 수 있습니다.

실제로 시중의 외장하드 케이스처럼 SATA를 USB 신호로 변환하는 방식을 검토했으나, 모든 디스크에 개별 외장 케이스를 장착하기에는 디스크 본체 가격과 맞먹는 수준의 비용 부담이 너무 컸습니다.


따라서 비용을 아끼기 위해 모든 디스크에 외장 케이스를 씌우는 대신, 하드디스크를 USB 신호로 변환하는 제어부는 유지하되 자동 탈부착이 일어나는 '디스크와 캐리지 장치 간의 인터페이스'에 별도의 커넥터를 적용하기로 했습니다.

이 커넥터는 자동화 탈부착이 쉬우면서도 SATA의 100옴(Ω) 임피던스에 대응하여 고속 데이터 전송이 가능해야 했습니다.

초기에는 포고핀을 고려했으나 임피던스를 맞추기 어렵고 스텁(Stub) 문제가 발생할 수 있어 제외되었고, 마찬가지로 100옴 규격인 RJ45와 USB 커넥터를 두고 최종 저울질을 했습니다.


결과적으로 내부 핀 개수가 24개로 넉넉한 USB-C 커넥터를 활용하기로 결정했습니다. 

만약 24개의 선이 들어간 기성 USB-C 케이블을 그대로 사용한다면 기존 SATA 케이블처럼 유연성이 떨어지는 문제가 다시 발생하므로, 케이블을 그대로 쓰지는 않습니다.

대신 USB-C 커넥터 부품만을 가져와 규격 외의 비표준 방식으로 신호와 전원을 배열하여 사용하기로 했습니다. 

결론적으로, 구조 내부에서 SATA를 USB 신호로 변환하여 통신하는 틀은 유지하면서, 물리적인 자동 탈부착 부위의 커넥터만 내구성과 임피던스 매칭이 우수한 USB-C 커넥터로 커스텀하여 문제를 해결했습니다.

### 1. 동작 방식

본 장치는 USB 인터페이스를 통해 제어되며, 구조적으로는 Z축이 제거된 H-bot 형태의 메커니즘을 채택했습니다. 

물리적인 구동부의 정밀도와 안정성을 확보하기 위해 리니어 레일과 GT2 타이밍 벨트를 조합하여 캐리지를 이동시킵니다. 

시스템의 두 축을 담당하는 스텝 모터는 A4988 드라이버로 제어되며, 부드럽고 정밀한 제어를 위해 마이크로스테핑은 1/4 분주율로 고정하여 구동합니다.


캐리지의 위치를 초기화하고 정밀하게 제어하기 위해 축별로 서로 다른 센서 아키텍처를 적용했습니다.

상하 위치의 원점(Origin) 및 한계점 인식에는 광축 기계식 키보드 스위치와 리미트 스위치를 혼용하여 정밀도와 물리적 안정성을 동시에 확보했습니다.

반면 좌우 위치 제어에는 슬롯형 옵토커플러(적외선 차단 센서)를 활용하여 비접촉 방식으로 슬롯의 위치를 정확하게 판별합니다. 

캐리지가 특정 하드디스크 슬롯에 접근하여 커스텀 USB-C 커넥터와 물리적으로 결합하면, 커넥터 내에 할당된 2개의 전용 핀을 통해 회로적으로 풀다운(Pull-down) 상태를 감지함으로써 USB 결착 여부를 확실하게 확인합니다.


장치에 입력되는 전원은 5V와 12V의 듀얼 라인으로 구성됩니다.

12V 전원은 3.5인치 하드디스크의 내부 모터 구동과 시스템의 스텝 모터를 구동하는 데 사용되며, 5V 전원은 메인 컨트롤러인 STM32F103 MCU를 구동하는 데 전용됩니다.

개별 하드디스크로의 최종 전원 공급은 12V 8핀과 5V 3핀 구조를 통해 이루어집니다.

안전한 전원 관리를 위해 캐리지의 USB 결착 신호가 확인되기 전까지는 전원이 차단되어 있으며, 디스크 보드에서 1핀의 제어 신호를 받아 USB 결착이 최종 확인된 순간 모스펫(MOSFET) 스위칭 회로가 동작하여 해당 하드디스크에 전원을 공급하기 시작합니다.


전원이 인가되어 인식된 하드디스크는 GPT(GUID 파티션 테이블)의 고유한 UUID를 기반으로 소프트웨어상에서 개별 식별됩니다. 

파일 시스템은 파일 아키텍처 수준에서 데이터 무결성을 보장하고 복제 및 스냅샷에 유리한 BTRFS로 포맷되어 자동화 백업 프로세스에 투입됩니다.
